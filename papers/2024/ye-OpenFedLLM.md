# OpenFedLLM: Training Large Language Models on Decentralized Private Data via Federated Learning

*Skimmed*

## Quick Notes
- A federated learning framework for training LLMs on private data; Uses two algorithms for instrustion-following capability (FedIT; an adopted supervised fine-tuning - SFT) and value alignment (FedVA; an dopted direct preference optimization - DPO) in federeated setup
- They implemented 7 FL baselines to compare each method for different purposes; all FL algorithms outperform the local training based on one clients data
